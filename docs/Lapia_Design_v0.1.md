## 1. アプリ概要

Lapia（ラピア）は、非恋愛・非性的な、匿名で話せる共感対話アプリの構想です。

- 誰にも頼れず孤立している人が、高額なサービスへの依存に頼らずに話せる場所を用意する
- 医療機関だけでは届きにくい「誰かに話を聞いてもらう時間」を補い、支援につながり直すきっかけをつくる

**特徴**

- 誰にも会わず、周囲に知られずに話せる
- 匿名の共感的なサポーターと1対1で会話する
- サポーター側の心の負担も守るGPT補助つき
- メッセージ機能・通話機能

## 2. 機能構成

```text
[ユーザー登録・設定]
   ├─ ニックネーム・プロフィール非公開設定
   ├─ 稼働時間（利用者／サポーター両方）
   └─ 感情タグ初期設定

[感情選択マッチング]
   ├─ 「寂しい」「誰かに怒ってる」「死にたいほどではないけど……」等のタグ選択
   └─ タグごとに相性の良いサポーターを一覧表示／顔と声で登録したサポーターの中から選べる

[共感チャットルーム]
   ├─ テキストチャット（GPT補助 ON/OFF 選択）
   ├─ 音声会話（β以降）
   ├─ GPT補助機能（返信候補／ストレス度スコア）
   └─ セッション時間制限（10分／20分／30分）

[会話後処理]
   ├─ 利用者の気分変化ログ（5段階で記録）
   ├─ 感謝／フィードバック（サポーター向け）
   └─ 自動ログ削除タイマー設定（即時〜30日）

[報酬・決済]
   ├─ Stripe連携による前払い式
   ├─ 利用時間別料金（例：10分300円）
   └─ 売上の一部をサポーターに分配（60〜70%）、残りを運営側で分配

[セキュリティ・倫理機構]
   ├─ 会話の暗号化保存（自端末のみ／クラウド選択制）
   ├─ NGワード・危機ワードフィルター
   └─ GPTによる危機検知アラート（自傷傾向・依存傾向など）

[サポーター保護機能]
   ├─ GPT共感支援 ON/OFF の切り替え
   ├─ 応答疲労アラート（AI分析）
   └─ サポーター同士の匿名コミュニティ（β以降）

[オプション機能（α後）]
   ├─ 会話メモのPDF出力
   ├─ セルフケア日記機能
   └─ Lapia ステルスモード（完全非表示起動）
```

## 3. 画面遷移

```text
起動
 ↓
[ホーム画面]
 ├─ 今日の気持ちを記録 → 感情タグを選ぶ → GPT補助 ON/OFF を選ぶ
 ├─ サポーター一覧表示（タグ適合順）
 │      └─ サポーターを選ぶ → セッション料金確認 → 開始
 │
 └─ Careルーム（チャット）
       └─ 会話中：GPT返信候補表示／ユーザーの入力
                 ↓
           終了ボタン → 気分ログ入力 → サポーターへの評価（任意）
                 ↓
           決済処理（前払い差額調整） → 自動ログ削除設定へ
 ↓
[設定／プロフィール管理]
 ├─ 利用可能時間の設定
 ├─ 支払い履歴確認／領収書DL
 └─ セキュリティ設定（暗号化・削除タイミング）
```

## 6. 悪用防止策（設計・運用レベル）

| 想定リスク | 対策 |
|---|---|
| ステルスモードの乱用 | 信頼スコアの導入。匿名性は守りつつ、サポーター・ユーザーそれぞれに内部評価スコアを持たせる。長期利用者・高評価者ほどステルスモードの使用を許可し、初回は使用不可。 |
| 複数アカウントによるなりすまし | 端末・挙動ベースの識別。Firebase Auth＋ローカル端末情報（UUIDやアプリ内識別子）でマルチアカウントを検出。類似文体・短期間での複数アカウント作成をAIで検知。 |
| サポーターへの嫌がらせ | 一時ブロック＋再マッチ制限。特定ユーザーへの通報・ブロックが一定数あると、そのアカウントは一定期間マッチング不可。悪質利用者はマッチング候補から除外。 |
| 依存傾向の過剰使用 | GPT＋利用頻度アラート。「毎日何時間も」「深夜帯連続」などの行動パターンを検知し、「利用が続いています。セルフケア日記を試しますか？」等の穏やかな介入メッセージを提示。 |
| 暴言・性的表現 | 危機ワード＋文脈解析。単語フィルタだけでなく文脈依存のNG表現フィルタを実装し、自動でセッションを遮断＋ログ記録（ユーザーには通知しない）。 |
| サポーターの疲労・バーンアウト | 稼働制限＆感情アラート。応答内容から「共感疲労」「被影響」などをスコア化し、閾値を超えたら自動でログアウト。サポーターにも「休憩をおすすめします」と通知。 |
| 通話機能の不適切使用 | 録音禁止通知＋即時遮断。音声通話はβ以降に導入し、通話中にNGワードを検出したら自動切断＋警告。相手の音声保存は全面禁止とし、ガイドラインで明示。 |
| 被害報告への対応遅れ | AI×人間の2段階通報審査。通報ボタン→AIが初期判定（緊急性・暴力性・性的リスク等）。一定以上の深刻度は管理者が48時間以内に対応。 |
| 無料アカウントでの嫌がらせ | 課金情報とアカウントを関連付け、「無料で嫌がらせだけして消える」パターンを防ぐ。「通話セッションはカード認証者のみ」などの層別運用も検討。 |
| フィッシング・外部誘導 | チャット内でのURL送信を禁止（GPTが検知・遮断）。「LINE教えて」「会いたい」などの誘導表現もフィルタ対象。 |
